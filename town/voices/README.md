# 녹음 대사

`lines.csv`에 앱이 읽어 주는 대사가 번호와 함께 들어 있어요. `핵심`에 O가 붙은 30줄부터 녹음하면 돼요.

1. 대사 하나당 소리 파일 하나를 만들고, 파일 이름을 번호로 지어요. 예: `001.mp3`
   - mp3를 권장해요. m4a, wav, ogg, webm도 돼요.
2. 파일을 이 폴더(`town/voices/`)에 넣어요.
3. `python3 claw-machine/build.py`를 실행한 뒤 커밋하고 푸시해요.

녹음 파일이 있는 대사는 그 파일을 재생하고, 없는 대사는 기기 목소리로 읽어요.
숫자나 가격이 들어가는 대사(예: "사과는 1000원! 모두 3000원.")는 목록에 없고, 항상 기기 목소리로 읽어요.
대사 글자를 바꾸면 `lines.csv`의 같은 줄도 똑같이 고쳐야 해당 녹음이 이어져요.
